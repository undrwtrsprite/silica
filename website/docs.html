01 / Installation

Requirements & first run

Silica runs Minecraft Beta 1.7.3 natively on Apple Silicon without Rosetta 2. The repository ships zero Mojang code, jars, or assets — you bring your own copy of Minecraft: Java Edition.

System requirements

  • Apple Silicon Mac (arm64 — M1 or newer)
  • macOS 14 Sonoma or later
  • Microsoft account owning Minecraft: Java Edition
  • ~17 MB for Silica.app + local JDK/assets cache

First-launch flow

  1. Mount Silica-0.2.1.dmg and drag Silica to /Applications.
  2. Sign in with Microsoft on the Play page (tokens are stored in the macOS Keychain for the session).
  3. Silica downloads or verifies the clean b1.7.3 jar against Mojang's SHA-1 checksum, prepares it locally, and launches via the native arm64 JDK 21 runtime.
02 / Architecture

How Silica patches & runs Beta 1.7.3

Your original Beta 1.7.3 jar is never modified in place. Instead, Silica splits preparation, bytecode patching, platform shimming, and rendering across dedicated modules:

ModuleRole
tools/mcprep/Uses ASM and RetroMCP-Java mappings to remap the clean jar to readable names, widen access, and redirect LWJGL 2 calls to Silica's platform layer.
agent/Java agent applied at launch that injects patch definitions from hooks/ (dev.betavk.hooks.PatchSet) as classes load.
hooks/Silica's own implementations for chunk workers, LOD meshing, inventory QoL, options screens, F3 overlay, and OpenAL Soft sound.
platform/GLFW / LWJGL 3 compatibility shim preserving the LWJGL 2 API (Display, Keyboard, Mouse) and LWJGL 2 key codes.
game/Generated dev.betavk.render.Renderer interface routing all 1,161 GL calls to either the Vulkan 1.2 (MoltenVK) backend or OpenGL.
launcher/SwiftUI macOS 14+ app handling Microsoft OAuth, isolated instances, world backups/import/export, auto-updates, settings, and benchmarks.
03 / Graphics

Vulkan renderer, render distance & LODs

Silica replaces Beta's 4-preset render distance toggle with a 2–32 chunk slider (F cycles {2, 4, 8, 12, 16, 20, 24, 32}), scaling linear fog and far clip automatically.

Vulkan & chunk workers

  • Translates fixed-function Beta rendering onto Vulkan 1.2 over MoltenVK/Metal with mip-mapped textures, pipeline caching, and hardware occlusion queries (CaveCull).
  • Threaded chunk generation (default 2 workers) and meshing (default 1 worker) are verified byte-identical to vanilla paths.
  • Hoisted Perlin noise, direct-chunk lighting, time-budgeted light updates, and O(N) dirty-queue bucketing remove chunk-edge hitches.

Real-block distant LODs

Open Options → Video Settings → LOD Settings to configure distant terrain (off by default):

  • 5-tier real-block quadtree: Near LODs render at 1×1×1 block detail and step smoothly down through 2×1×2, 4×2×4, 8×4×8, and 16×4×16 out to +128 extra chunks.
  • Supports live player block edits, saved McRegion worlds, and day/night emissive lighting.
  • LOD Detail & Extra Chunks sliders let you trade distant detail for thermal headroom on long sessions.
04 / Gameplay & QoL

Inventory, controls, audio & debug

Core Beta 1.7.3 gameplay and physics remain vanilla (no sprinting, hunger, or modern combat changes). Quality-of-life improvements stay strictly ergonomic:

Inventory

  • Drag to spread stacks across slots
  • Hover + 1–9 to swap with hotbar
  • Q drops one; Ctrl+Q drops full stack
  • Shift + double-click moves all matching stacks
  • Scroll wheel over a slot transfers 1 item
  • Sort button + Shift-click bulk crafting + durability numbers

Controls & HUD

  • FOV & mouse sensitivity sliders in Options
  • Sneak toggle option & smooth zoom key
  • Middle-click pick block
  • GUI scale 1×–4× & optional FPS counter
  • Expanded F3 screen & optional cheats with Tab completion

Audio & menus

  • OpenAL Soft audio backend
  • Master, Music, Effects, and Ambient sliders
  • Optional directional sound captions
  • Sortable world list showing seeds, plus direct Resume on title screen
05 / Saves & Instances

World compatibility, skins & instances

Worlds & multiplayer

  • McRegion parity: Verified against Mojang's own Beta 1.7.3 server with 0 differences on load/re-save; terrain generation matches to 0.005%.
  • Back up worlds to zip, import existing saves, or export them back out from the launcher's Worlds tab. Persistent LOD caches stay cleanly inside saves/<world>/lod/.
  • Skins and capes load via dev.betavk.net.Skins; online-mode multiplayer is supported with -Dbetavk.joinUrl.

Isolated instances

On the launcher's Instances tab, create separate Beta 1.7.3 profiles with independent saves, configs, and per-instance overrides:

  • Per-profile isolation: Separate world folders, options, and Vulkan/OpenGL or fullscreen settings.
  • Visual & movement QoL: Better Grass (Off, Fast, Fancy) in Video Settings plus /fly [on|off|speed <val>] when commands are enabled.
06 / Development

Building & testing from source

Requires Apple Silicon macOS, Xcode Command Line Tools, Homebrew openjdk@21 (arm64), and gradle.

Commands

# 1. Select arm64 JDK 21 and prepare your clean Beta 1.7.3 jar (once)
source scripts/env.sh
scripts/mcprep.sh /path/to/your/b1.7.3-client.jar

# 2. Run the patched client directly
scripts/run-patched.sh

# 3. Stage game jars & build Silica.app / DMG
gradle :hooks:stageGame
cd launcher && ./build_app.sh
swift test                    # launcher unit tests
./make_dmg.sh                 # packs Silica-<version>.dmg

# 4. Run automated fixed-seed benchmarks (seed 1337)
scripts/bench.sh my-label
07 / Reference

JVM flags & environment variables

Switch / VarDescription
-Dbetavk.backend=vulkan|glSelects Vulkan (MoltenVK) or OpenGL backend.
-Dbetavk.meshworkers=NNumber of chunk meshing worker threads (default 1).
-Dbetavk.genworkers=NNumber of terrain generation worker threads (default 2).
-Dbetavk.vsync / -Dbetavk.uncappedForce VSync on or uncap frame rate.
-Dbetavk.fullscreen=trueLaunch directly into fullscreen.
-Dbetavk.vkstatsPrint Vulkan renderer frame/pipeline diagnostics.
-Dbetavk.gamedir / -Dbetavk.assetsOverride game directory or asset store path (BETAVK_HOME, BETAVK_ASSETS).
-Dbetavk.skins=offDisable background Mojang skin/cape lookups (or override with -Dbetavk.skinUrl / -Dbetavk.cloakUrl).
-Dbetavk.test=hud|video|inv|world|fly|skinsRun automated TestHarness checks against the patched client.
08 / Troubleshooting

Common issues

macOS says Silica is damaged or unverified

Silica is ad-hoc signed rather than Apple-notarized. Clear the quarantine attribute or right-click Silica.app → Open once:

xattr -cr /Applications/Silica.app

Missing sounds in dev builds

Point BETAVK_ASSETS at a Mojang asset store containing indexes/b1.7.json and objects/, or let the launcher populate ~/Library/Application Support/BetaVulkan/assets on first run.

Open an issue on GitHub
