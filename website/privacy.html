Privacy Policy

Last updated 12 November 2026

Silica has no accounts, no servers of its own and no analytics. It does not collect, store or sell your personal data. Everything it keeps stays on your Mac. The only network traffic is between your Mac and Microsoft, Mojang and the download hosts listed below.

Who this covers

Silica is a launcher and an improved build of Minecraft: Java Edition Beta 1.7.3 for Apple Silicon Macs, made by an independent developer (GitHub: undrwtrsprite). This policy covers the Silica launcher app and this website.

Signing in with Microsoft

Silica asks you to sign in with the Microsoft account that owns Minecraft: Java Edition, to check that you own the game before it starts.

  • How it works. Sign-in happens on Microsoft’s own page (login.microsoftonline.com) in a system web sheet. Silica never sees your Microsoft password. It asks only for two permissions: XboxLive.signin, which Minecraft sign-in needs, and offline_access, which lets Silica keep you signed in.
  • What Silica receives. A Microsoft access token and refresh token, an Xbox Live token, a Minecraft Services token, whether your account owns Minecraft: Java Edition, and your Java Edition profile name (your in-game username).
  • Where it goes. Silica talks directly to Microsoft (login.microsoftonline.com), Xbox Live (user.auth.xboxlive.com, xsts.auth.xboxlive.com) and Minecraft Services (api.minecraftservices.com). Nothing is sent to the developer or to any other third party.
  • What it is used for. Only to verify ownership and to start the game with your username.
  • How long it is kept. The access, Xbox and Minecraft tokens stay in memory only, and are renewed while Silica is open. So that you stay signed in, Silica saves the refresh token in your Mac’s Keychain, protected by macOS so other apps cannot read it without your permission, and only while this Mac is unlocked. It is never written to a plain file and never leaves your Mac except to ask Microsoft for new tokens. When Silica opens, it uses that token to sign you in again and re-checks that you still own the game.
  • Signing out. Choosing Sign out deletes the refresh token from the Keychain, and nothing is kept. If Microsoft stops accepting the token (for example you changed your password or revoked access), Silica deletes it and shows you signed out.

You can also remove Silica’s access at any time from your Microsoft account’s app permissions page (account.live.com/consent/Manage). That invalidates the saved token.

Downloads on first run

Setup downloads files straight to your Mac. Each host sees your IP address and ordinary request details, under its own privacy policy.

  • Java 21 for Apple Silicon from Eclipse Adoptium (api.adoptium.net).
  • Minecraft Beta 1.7.3 and its sounds from Mojang (piston-meta.mojang.com, resources.download.minecraft.net), checked against the checksums Mojang publishes.
  • An open-source name-mapping tool, RetroMCP-Java, from GitHub (github.com/MCPHackers).

What stays on your Mac

Settings, Java, the game files, your worlds, logs and benchmark results live in ~/Library/Application Support/BetaVulkan. None of it is uploaded. Deleting that folder removes it.

The game

The game itself has no telemetry. It connects to a multiplayer server only if you choose to join one, and that server’s operator has their own policies.

Joining multiplayer servers. Servers that check who you are (online mode) need proof from Mojang that you are signed in. When you join one, Silica gives the game your Minecraft sign-in token, and the game sends it, with your profile id and the server’s join code, to Mojang’s session server (sessionserver.mojang.com). The server then asks Mojang to confirm your name. The token is handed to the game through its environment, not its command line, is kept only in memory while the game runs, and is never written to disk or sent anywhere else. Servers you join receive your player name and profile id from Mojang, and have their own policies.

Skins and capes. To show each player’s skin and cape, the game looks up the name of every player in your game (you, and anyone on a server you join) at Mojang’s servers (api.minecraftservices.com and sessionserver.mojang.com), then downloads the pictures from textures.minecraft.net. Only a player name is sent, and Mojang sees your IP address as with any request. Mojang limits how often these lookups are allowed, so the game remembers the answers (player names and the addresses of their skin and cape pictures) in a small file called betavk-skins.txt in your game folder, and asks again only after a few hours. Nothing is sent anywhere except to Mojang as described. Delete that file to forget them. You can turn this off in Silica’s Settings (“Show player skins and capes”), and everyone then shows as the default skin.

This website

The site is a static page with no cookies, no forms, no analytics and no advertising. It is hosted on Vercel, which keeps standard server logs (such as IP address and requested page) for security and operations under Vercel’s own privacy policy.

Children

Silica is not aimed at children and does not knowingly collect information from anyone. Minecraft’s own age rules and Microsoft’s account rules apply when you sign in.
