01 / Install

Three steps, once.

  1. Drag it to Applications

    Open the disk image and drag Silica into Applications.

  2. Allow it once

    Silica is unsigned, so macOS blocks the first open. Click Open Anyway.

    System SettingsPrivacy & Security ›
    "Silica" was blockedOpen Anyway

  3. Sign in and play

    Sign in with Microsoft. The first run downloads Beta 1.7.3 from Mojang and checks it against Mojang's checksum.

03 / FAQ

Questions

Is it vibecoded?

Yes, openly AI-assisted. It's open source under GPL-3.0, so you can read every line.

Why does macOS block it?

It's unsigned. Go to System Settings → Privacy & Security → Open Anyway.

Do I need to own Minecraft?

Yes, a Java Edition account.

Is it free?

Yes.

Does it ship Mojang files?

No. They're downloaded on first run and checksum-verified.

Will my old worlds work?

Yes. They stay plain Beta 1.7.3 worlds, so the original game and servers can open them.

Other versions?

Other Betas and Alphas are coming.

Mods?

Basic and experimental for now.

Intel Macs?

No. Apple Silicon, macOS 14+ only.
